## Добавление новых данных проекта

1. Добавьте все файлы в Git:
2. Проверьте, что все Issues заполненны в "Todo" на Kanban доске
3. git add .
4. git commit -m "Реализована авторизация с переходом на успешную страницу" при желании закрыть Issues с помощью команды git commit -m "Готово; closes #1" --#1 - номер задачи
5. git push origin main
6. Проверьте, что все Issues перемещены в "Done" на Kanban доске
